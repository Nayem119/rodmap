## 🛡️ Year 2: Cyber Security Mastery

### 📌 Months 13-15: Networking Foundation + Wireshark + Firewall + VPN

*   **Week 1 (OSI, TCP/IP, Subnetting):** Design a 50+ device network simulation using Cisco Packet Tracer. Master VLSM, CIDR, and routing table structures.

*   **Week 3 (VPN Architecture):** Implement OpenVPN and WireGuard servers on a cloud VPS (e.g., DigitalOcean). Set up end-to-end client routing configurations.
*   **Week 4 (Nmap & Network Scanning):** Master advanced scanning techniques (`-sS`, `-sT`, `-sU`), OS fingerprinting, and writing custom Nmap Scripting Engine (NSE) automation scripts.
*   **Week 5-6 (Wireshark Mastery):** Master capture filters (`ip.src`, `tcp.port`), stream reconstruction, SSL/TLS decryption keys, and spotting malicious activity in PCAP forensics files.
*   **Week 7-8 (Man-in-the-Middle):** Set up MITM simulations using Ettercap/Bettercap. Test ARP Spoofing/DNS Poisoning defenses and implement local Iptables filtering walls.
*   **Week 9-12 (IDS/IPS & Audit):** Install Snort IDS, write custom detection rules for network anomalies, perform Zeek logs analysis, and write an enterprise network security audit report.

## 🏆 Pro-Level Learning Rules

1. **The 20% Theory Rule:** Do not spend more than 20% of your dedicated time reading or watching videos. Spend the remaining 80% actively writing code, breaking environments, configuring pipelines, and debugging errors.
2. **The Documentation First Policy:** When a tool fails or throws an error, resist looking up instant answers immediately. Read the official reference documentation first to thoroughly understand the structural design patterns.
3. **The Clean Code Commit Standard:** Treat every single repository commit as if it is heading directly into a production system. Write highly descriptive commit histories, document all architecture layout maps within markdown fil
